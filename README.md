# TheGluttonHamstersRunAway_2021
2021년도에 만들었던 게임에서 본인이 했던 부분만 발췌하여 저장해두었습니다.

* * *
## 먹보 햄스터의 가출 게임 개요
제작했던 게임은 배고픈 햄스터가 케이지를 탈출해서 숨겨진 간식을 먹으려고 한다는 내용의 2D 캐주얼 게임으로, 키보드만 사용해서 진행되는 게임입니다.
상하좌우 키, 스페이스 바, Tab 키, Z 키가 사용됩니다.
주로 사용하는 씬은 시작화면 씬, 케이지 씬, 메인 씬, 미니게임 씬, 엔딩 씬입니다.

### 포만감 시스템
- 초기 포만감 100, 최대 포만감 1000을 가집니다. 포만감을 모두 채우면 게임 승리, 엔딩으로 이어집니다. 모두 채우지 못하고 0이 되면 게임을 패배합니다.
- 포만감이 상승하는 조건은 간식을 섭취하는 것입니다. 모든 간식은 90의 포만감을 채워줍니다.
- 포만감이 감소하는 조건은 캐릭터가 이동하는 것입니다.

### 라이프 시스템
- 라이벌이자 조력자 캐릭터와의 미니게임 직후, 랜덤하게 발생하는 이벤트로, 10초 이내에 케이지 안에 숨어야 무사히 이벤트가 끝납니다.
- 해당 이벤트에서 실패하면 라이프가 감소합니다.
- 라이프가 모두 감소하면 '가출 엔딩'을 보게 됩니다.

### 전체 미니게임
- 총 4개의 미니게임이 있습니다. 카드 짝 맞추기, 떨어지는 물건 피하기, 스페이스 바 연타 게임, 방향키 맞추기 게임입니다.
- 각 게임에는 시간 제한이 있으며, 시간 안에 미니게임을 클리어하거나 제한 시간 동안 버텨야 합니다.
- 미니게임은 쉬움과 어려움의 두 가지 난이도가 존재합니다.
- 미니게임을 클리어하면 간식이 제공됩니다. 난이도에 따라 받는 간식의 개수가 다릅니다. 쉬움 난이도는 1개, 어려움 난이도는 2개 입니다.

### 엔딩
- 잔류 엔딩, 가출 엔딩, 굶주린 엔딩의 세 가지를 가지고 있습니다.

## 담당 작업
### 게임 기본 흐름
- 씬에서 플레이어가 상하좌우로 이동할 수 있도록 설정했습니다. 추가로, 특정 씬(케이지  씬, 특정 미니게임 씬)에서 점프를 할 수 있도록 했습니다.
- 각 가구와 상호작용할 수 있도록 했습니다. 가구로부터 간식을 얻거나, 혹은 미니게임을 할 수 있는 씬으로 이동합니다.
- 엔딩 조건을 달성 시 엔딩으로 연결하도록 했습니다.

### 포만감 시스템 작업
- 기존에 기획했던 대로 초기 포만감은 100, 최대 포만감을 1000을 가집니다.
- 간식을 먹을 수 있는 탭을 만들어, 해당 탭이 열렸을 때만 간식을 먹을 수 있도록 했습니다. 간식에 적힌 번호 키패드를 누르면 간식을 먹을 수 있습니다.
- 간식을 먹으면 90의 포만감을 채웁니다.
- 포만감을 모두 채우면 잔류 엔딩으로 이어지도록 했습니다.
- 포만감이 모두 떨어지면 굶주린 엔딩으로 이어지도록 했습니다.

### 라이프 시스템 작업
- 10초를 주기로 이벤트 진행을 할지 말지 결정합니다. 35%의 확률으로 이벤트가 진행되도록 했습니다.
- 이벤트가 진행되면 '조력자 캐릭터'를 등장시켜 씬에서 '숨어야 하는 곳'을 안내하도록 했습니다.
- 성공적으로 숨었다면 아무런 변동 없이 이벤트 종료, 다시 10초를 주기로 이벤트를 진행할지 말지 결정합니다.
- 이벤트에서 성공적으로 숨지 못했을 경우, 라이프를 감소시키고 다시 플레이어가 케이지 씬으로 이동하도록 했습니다.
- 라이프가 모두 감소할 경우, 가출 엔딩으로 이어지도록 했습니다.

### 방향키 맞추기 미니게임
- 4가지 패턴을 미리 정해두고, 패턴 한 줄을 모두 클리어하면 다시 랜덤하게 패턴을 결정합니다.
- 상, 하, 좌, 우 키보드 방향키만으로 미니게임이 진행됩니다.
- 방향키를 맞추지 못하고 틀렸을 시, 미니게임 내에서 사용하는 라이프가 하나 감소합니다. 최대 세 번의 기회가 있습니다.
- 난이도에 따라 패턴을 몇 번 클리어해야 하는지 다르게 설정해두었습니다. 쉬움이면 5번, 어려움이면 10번입니다.
- 세 번 이상 틀렸거나 20초의 제한시간 내로 클리어하지 못하면 아무것도 간식을 얻을 수 없습니다.
- 쉬움 난이도를 클리어하면 간식 1개를 받습니다. 어려움 난이도를 클리어하면 간식 2개를 받습니다.
